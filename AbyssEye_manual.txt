AbyssEye 取扱説明書
対象ブランチ: AbyssEye-Neo

1. このソフトでできること

AbyssEye は、TIFF 画像やリアルタイム取得画像をもとに、ROI 抽出、推論、DeepScan による確認、手動ラベル修正、細胞数集計を行うためのツールです。

主な用途は次の 2 つです。
- 保存済み画像をプロジェクト単位で整理して処理する
- 顕微鏡などから送られる最新画像をリアルタイムで確認し、そのまま保存・修正する


2. 起動方法

初回セットアップ:
./scripts/setup-dev.sh

起動:
./scripts/dev-up.sh

起動後、ブラウザで次を開きます。
http://localhost:3000

トップ画面で「バックエンドAPIが利用可能です」と表示されていれば利用できます。


3. 画面構成

トップ画面には主に次の入口があります。

- ROI抽出
  保存済み画像またはリアルタイム画像を処理します。
- モデル管理
  推論で使う TensorFlow / Keras モデルを登録し、アクティブモデルを切り替えます。

ROI抽出の中には次の 2 つの入口があります。

- データベース
  プロジェクトを作成し、画像や同視野画像ファイルをアップロードして処理します。
- リアルタイムエンジン
  最新画像を確認しながら保存、DeepScan、手動修正を行います。


4. 使い始める前の準備

推論を使う場合は、先に「モデル管理」でモデルを登録してください。

操作手順:
1. トップ画面で「モデル管理」を開きます。
2. 「モデルをアップロード」または「フォルダごとアップロード」を押します。
3. 一覧に追加されたモデルのうち、使いたいものを「アクティブ化」します。

補足:
- アクティブなモデルには「Active」と表示されます。
- 推論結果が必要な画面では、このアクティブモデルが使われます。


5. データベース画面の使い方

5-1. プロジェクトを作成する

1. トップ画面から「ROI抽出」→「データベース」を開きます。
2. 「プロジェクト名」を入力します。
3. 「プロジェクトを保存」を押します。
4. 一覧に作成されたプロジェクトの「開く」を押します。

補足:
- プロジェクトは画像を整理するための単位です。
- 一覧の「保存」はプロジェクトのダウンロードです。
- 不要になったプロジェクトは「削除」で消せます。


5-2. 画像をアップロードする

プロジェクトを開いたあと、次のどちらかで画像を追加します。

- 「画像アップロード」
  単一画像を追加します。
- 「同視野画像ファイルをアップロード」
  同じ視野の複数画像ファイルを追加します。

画面には次の 2 つの一覧が表示されます。

- 画像リスト
  単一画像が表示されます。
- 同視野フォルダリスト
  同一視野の複数画像フォルダが表示されます。


5-3. 単一画像を処理する

画像リストでは次の操作ができます。

- 「ROI抽出&推論」
  単一画像をまとめて処理します。
- 「DeepScan」
  ROI 抽出と推論が終わった画像を DeepScan で開きます。
- 「保存」
  元画像を保存します。
- 「削除」
  画像を削除します。

補足:
- DeepScan は、対象画像の ROI 抽出と推論が終わっていないと開けません。
- すべての単一画像に推論結果がそろうと「セルカウント」が使えるようになります。


5-4. 同一視野の複数画像フォルダを処理する

同視野フォルダリストでは次の操作ができます。

- 「一覧」
  フォルダ内の画像一覧を開きます。
- 「マージ画像ROI抽出」
  フォーカスマージ画像を作成し、その結果を単一画像側へ追加します。
- 「削除」
  フォルダを削除します。

運用の目安:
- まず 同視野画像ファイル をアップロードする
- 必要なら「マージ画像ROI抽出」を実行する
- 追加された単一画像を「ROI抽出&推論」で処理する
- 必要に応じて DeepScan で確認する


5-5. フォルダ内画像一覧を使う

「一覧」を開くと、そのフォルダ内の画像ごとに処理できます。

主な操作:
- ROI 抽出
- 推論
- DeepScan
- 保存

複数画像フォルダの中身を 1 枚ずつ確認したいときに使います。


5-6. セルカウント結果を出力する

単一画像の推論がそろったら「セルカウント」を押します。

結果画面では次の操作ができます。
- 再読み込み
- CSV出力
- A4 PDF出力

レポートを保存したい場合はこの画面を使ってください。


6. リアルタイムエンジンの使い方

1. トップ画面から「ROI抽出」→「リアルタイムエンジン」を開きます。
2. プロジェクトが未選択なら、新しいプロジェクト名を入力して作成します。
3. 画面中央に最新画像が表示されます。
4. 必要に応じてサンプル名を入力します。
5. 必要なら「Stack mode」を ON にします。
6. 「保存」を押して現在の画像をプロジェクトへ保存します。

保存後の考え方:
- 保存した画像は後から DeepScan やプロジェクト画面で見直せます。
- 連続取得中に、その時点の最新画像を保存する用途を想定しています。


6-1. リアルタイム画面の主な表示切替

リアルタイム画面では次の切替ができます。

- 画像表示: Raw / Normalized / Jet / Optical Boost
- ラベル基準: AI / Manual
- Deep Scan スイッチ
  ROI の枠表示や検出状況を重ねて確認します。

補足:
- Manual を選んでも manual label が未設定の ROI は AI ラベルが使われます。


6-2. リアルタイム画面での手動修正

リアルタイム画面では次の手動修正ができます。

- 手動ROI追加
  「手動ROI追加」を ON にして画像上をクリックすると 48x48 ROI を追加します。
- 手動ROI削除
  手動で追加した ROI を選択して削除します。
- Manual Label
  ROI を選択して 0 / 1 / 2 / 3 またはラベルなしを設定します。

推論プレビューでは、ROI のサムネイルを別クラスの枠へドラッグ＆ドロップすると manual_label を更新できます。


7. DeepScan の使い方

DeepScan は、保存済み画像やリアルタイム画像に対して ROI と推論結果を詳しく確認する画面です。

主な開き方:
- データベース画面の「DeepScan」
- リアルタイム保存後の DeepScan 関連画面
- フォルダ一覧からの DeepScan

主な操作:
- Raw / Normalized / Jet / Optical Boost の切替
- AI / Manual 表示基準の切替
- ROI 枠の表示確認
- 選択 ROI のプレビュー確認
- manual label の更新
- 手動 ROI の追加 / 削除
- クラス別プレビューへのドラッグ＆ドロップによる再分類
- 前後ボタンによる画像送り
- 再読み込み

DeepScan は「確認・修正・再分類」の中心画面として使います。


8. クラス番号の意味

推論結果のクラス番号は次の意味です。

- 0 = 単一細胞
- 1 = 複数細胞
- 2 = ピンぼけ
- 3 = 非細胞粒子

manual label を付けると、AI 判定よりも手動判定を優先して表示できます。


9. 典型的な運用例

9-1. 保存済み画像を処理する場合

1. モデル管理でモデルをアクティブ化する
2. ROI抽出 → データベースを開く
3. プロジェクトを作成する
4. 画像または同視野画像ファイルをアップロードする
5. 単一画像なら「ROI抽出&推論」を実行する
6. 必要に応じて DeepScan で結果を確認・修正する
7. 必要ならセルカウント結果を CSV / PDF で保存する


9-2. リアルタイム取得画像を処理する場合

1. モデル管理でモデルをアクティブ化する
2. ROI抽出 → リアルタイムエンジンを開く
3. プロジェクトを作成する
4. 最新画像を確認する
5. 必要ならサンプル名や Stack mode を設定する
6. 「保存」を押す
7. DeepScan で ROI とラベルを確認・修正する


10. 更新方法

すでに clone 済みの環境で、開発者の新しい更新を取り込む場合は次を実行してください。

git checkout AbyssEye-Neo
git pull --ff-only origin AbyssEye-Neo
./scripts/setup-dev.sh

そのあと起動:
./scripts/dev-up.sh

もし git pull が止まった場合は、ローカルの未コミット変更や独自コミットが原因の可能性があります。必要に応じて変更を退避または commit してからやり直してください。


11. 困ったとき

- トップ画面でバックエンド接続エラーが出る
  バックエンドが起動していない可能性があります。README の起動手順を確認してください。

- 推論できない
  モデル管理でアクティブモデルが設定されているか確認してください。

- DeepScan が開けない
  対象画像の ROI 抽出や推論がまだ終わっていない可能性があります。

- 手動削除できない ROI がある
  削除できるのは手動追加した ROI のみです。

- 最新コードに更新したのに動作がおかしい
  `./scripts/setup-dev.sh` を再実行して依存関係を入れ直してください。
